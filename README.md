This is a mod intended to add a truckload of gun parts to your game, everything from AR handguards to magazines. 500 items and counting!

Please report all bugs in the issues tab.

How to install:

1. Download the latest release from the releases tab.
2. Open the downloaded 7z file with your choice of archive manager (DO NOT USE THE BUILT IN WINDOWS ONE)
3. Put the contents of the zip file into your base SPT folder
4. Enjoy!
